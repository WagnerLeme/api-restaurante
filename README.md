1. Criar rep no git e compartilhar com a equipe
2. clonar o rep e criar o projeto inicial
    - npm init -y
    - Instalar dependencias do proj
        - express
        - mongoose
        - dotenv
        - cors 

    - Instalar dep. dev
        - typescript
        - tsx
        - @types/node 
        - @types/express
        - @type/cors
        
3. npx tsc --init
    - "includ" 
    - "exclud"
    - target 
    - module 
    - rootDir
    - outDir
    - strict 
    - esModuleInterop 
    
4. Criar organização de pasta em camada (Monólito Modular)

5. Criar o script para executar projeto.
